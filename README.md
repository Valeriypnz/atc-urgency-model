# Управление процессами центра ОВД на основе индекса срочности

Исходный код дискретно-событийной имитационной модели и данные экспериментов к статье
«Метод управления процессами центра обслуживания воздушного движения на основе индекса
срочности при интеграции беспилотных авиационных систем».

Source code of the discrete-event simulation model and experiment data for the paper
“A Method for Managing Air Traffic Service Unit Processes Based on an Urgency Index under the
Integration of Unmanned Aircraft Systems”.

## Состав

| Файл | Назначение |
|---|---|
| `sector_model.py` | основная модель: жёсткая секторизация, варианты С1–С4, контрольные варианты |
| `ovd_simulation.py` | вся модель в одном файле с командной строкой: `python ovd_simulation.py`, `--x 5`, `--scan`, `--csv out.csv` |
| `ovd_model.py` | общие элементы и модель «общего пула» (раздел 6) |
| `run_experiments.py` | воспроизведение всех экспериментов статьи (разделы 5.3–5.5 и 6) |
| `make_figures.py` | построение рисунков 2–4 |
| `exp_real.py` | помощь по докладу в реалистичных условиях (задержка доклада, не более 25 % смены для руководителя полётов) и показатели худших задержек (раздел 5.3) |
| `exp_tail.py` | доля задач с нарушением норматива для остальных вариантов табл. 2 |
| `results/res.json` | результаты экспериментов, приведённые в статье |
| `results/res_real.json` | результаты `exp_real.py` и `exp_tail.py` |

## Запуск

Требуется Python 3.8+; модель использует только стандартную библиотеку,
для рисунков нужны `matplotlib` и `numpy`.

```bash
pip install -r requirements.txt
python run_experiments.py --quick   # пробный расчёт, ~15 с
python run_experiments.py           # полный расчёт, как в статье, ~3 мин
python make_figures.py              # рисунки в results/
python exp_real.py && python exp_tail.py   # табл. 2: С3р и доля нарушений
```

Каждому прогону назначается собственное начальное значение генератора, поэтому полный
расчёт воспроизводит числа статьи (например, _K_ = 0,861 и _R_ = 0,460 для С4 при _x_ = 20).

## Параметры (табл. 1 статьи)

| Класс | Интенсивность, ч⁻¹ | Среднее время, мин | Норматив | Вес |
|---|---|---|---|---|
| A — ОВД пилотируемых ВС | 32,4 (27 ВС/ч × 1,2 мин на пролёт) | 1 | 30 с | 1 |
| B — заявки на ИВП (часть работы диспетчера сектора) | x | 1 | 30 мин | 1 |
| C — координация и контроль БВС | 4x | 1 | 30 с | 1 |
| D — нештатные ситуации с пилотируемыми ВС и БВС | 0,0001(27 + x) | 15 | 30 с | 3 |

Время выполнения — логнормальное, коэффициент вариации 0,5; смена 7 ч, первый час
исключается; 3 сектора. Проверка при сменах 4 и 12 ч (`exp_shift.py`) даёт те же K с точностью до 0,003. Параметры задаются в `run_experiments.py` (объект `cfg`).
